**NusaStat — Indonesia in numbers.** A national statistics site for Indonesia: population, economy, prices, jobs and wellbeing, on seven linked pages with real figures from BPS — Statistics Indonesia, source and year on every number. Hand-drawn SVG charts (population trend, GDP growth, inflation, unemployment, poverty, HDI, sector mix), a sortable and filterable province table, an indicator search, and a phone layout. Static files only — no build step, no network requests; every figure lives in the site's own files.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Hand it in with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
